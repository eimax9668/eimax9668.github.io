GitHub Educationの恩恵

2026年8月29日

申請（意外にカンタン）

学生証を提出するだけで申請完了。一応英語での説明も書いておいた。

GitHub Copilotを使い放題かと思いきや

最初は「これでGitHub Copilotが使い放題！学生最高！ヤッター！」と思っていたが、実際は制限があることが分かった。 2026年6月からAIクレジット制に移行済みで、GitHub Copilotを使うと普通にクレジットが消費される。 GitHub Copilotの利用は月間200クレジットまで無料で、それ以上は有料になる。
つまり、学生プランでも使い放題ではない。ただコード補完はクレジット消費なしで無制限で使えるので、学生プランの恩恵は大きい。

Notion

他にも利用できるサービスがあり、Notionも利用可能だったので申請した。こっちは一瞬だった。
ここで一つ気をつけたいのが、「ワークスペースメンバーが1名以下のワークスペースのみが対象」 であるということ。つまり、Notionのワークスペースを作るときは、必ず自分一人で作ること。もし他の人と共同で作ってしまうと、学生プランの対象外になってしまうので注意。

他にできること

無料ドメイン（一年間）やプログラミング学習プラットフォームも利用可能らしいが、正直そこまで使いこなせそうにない。
